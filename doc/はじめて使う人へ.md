# はじめて使う人へ

作った本人以外がこのシステムを自分の配信で使うための手順。

---

## 最短ルート: コメント連動だけなら 3 行

認証もアプリ登録も要りません。

```
npm install
npm start                                          別の窓で: 中継サーバー
node twitch/twitch_bridge.js --chat あなたのチャンネル名
```

これで視聴者のコメントが演出になり、コメントが貯まるとメダルが入ります。
OBS のブラウザソースに `http://localhost:8787/enshutsu/enshutsu_overlay.html` を指定してください。

チャンネルポイント・ビッツ・サブスク・レイドも使いたい場合だけ、下の「フル機能にする」へ。

---

## 用意するもの

| | 要件 | 確認 |
| --- | --- | --- |
| Node.js | **18 以降** | `node -v` |
| Python | **3.10 以降** | `py -3 -V` または `python3 -V` |
| OBS | ブラウザソースが使えるもの | — |

Windows なら `setup.bat` をダブルクリックすれば、依存インストールから全起動までやってくれます。

## フル機能にする (3 ステップ)

### 1. Twitch の認証を通す

```
npm run twitch
```

ブラウザにコードを入れて承認するだけです。**アプリ登録も設定ファイルも要りません**
(`twitch/client_id.js` に配布元のクライアント ID が入っている場合)。
チャンネル名も指定不要で、承認した本人のチャンネルが使われます。

承認画面には **`slot-enshutsu-idol-katsudo`** というアプリ名が出ます。これがこのプロジェクトのアプリです。

トークンは Twitch から自分の PC へ直接発行され、配布元には渡りません。
自分のアプリで動かしたいときは `doc/twitch認証の取り方.md` を参照してください。

### 2. チャンネルポイント報酬を作る

Twitch のダッシュボード →「視聴者エンゲージメント」→「チャンネルポイント」で、
**この名前どおりに** 報酬を作ります。名前が 1 文字でも違うと反応しません。

**起動時に自動で照合します。** 名前が違えばコンソールにこう出ます。

```
[報酬] 次の報酬がチャンネルに見つかりません。反応しません:
         「100回転」→ 似た名前の「１００回転」があります (空白や全角半角の違い?)
```

| 報酬名 | 価格の目安 | 何が起きるか |
| --- | --- | --- |
| `100回転` | 500 pt | メダル 120 枚 (約 100 回転ぶん) |
| `10回転` | 50 pt | メダル 12 枚 |
| `設定変更` | 高め (10,000 pt など) | 電源を入れ直して設定を変える。**モデレータ限定** |

- 価格は `doc/twitch連携設計.md` の「ポイント価格の決め方」で逆算できます。
  同接 30 人・消化率 40% なら 500 pt が目安です。
- 名前を変えたいときは `twitch/rules.json` の `"reward"` も同じ名前に直します。
- 使わない報酬は `rules.json` からルートごと消してかまいません
  (**使わないイベントのスコープは承認画面にも出なくなります**)。

### 3. 自分の配信に合わせて数値を変える

`twitch/rules.json` を開いて調整します。**このファイルだけが人の編集対象**です。

| 項目 | 既定 | 目安 |
| --- | --- | --- |
| `guard.mods` | `[]` (空) | **自分の login 名を入れる。** 空のままだと「設定変更」が誰も使えません |
| `counter.goal` | 200 | チャット何コメントで 120 枚入れるか。同接 15 人・15 コメント/分で約 13 分に 1 回 |
| `guard.chatMedalsPerMinute` | 10 | チャット由来の 1 分あたり上限。連続稼働ラインの 58% |
| 押し順投票 | `"enabled": false` | 有効にすると出玉が確実に減ります (ナビ無視になるため) |

主制御側の起動オプション:

```
scripts\dev.cmd start -Credit        クレジット制 (メダルが尽きたら待機)
```

`--credit-init 500` が配信開始時のクレジット (約 427 回転 ≒ 29 分ぶん) です。
**設定は 1〜2 で運用してください。** 設定 3 以上は機械割が 100% を超えて下皿が増え続け、
視聴者が何もしなくても永久に回ってしまいます。

## 同梱の素材は差し替えてください

`enshutsu/` に入っている画像・音声・動画は **作った本人の素材**です。
そのまま配信に出すと権利の問題になります。

| フォルダ | 中身 | どうするか |
| --- | --- | --- |
| `enshutsu/yokoku/freeze/cutin/` | カットイン画像と音声 | **自分のものに差し替える** |
| `enshutsu/yokoku/freeze/` | フリーズ演出の GIF・動画・効果音 | 同上 |
| `enshutsu/yokoku/banner/sound/` | 予告バナーの効果音 (白/青/緑/赤/金.mp3) | 好きな音を置く。無くても動く |
| `enshutsu/at/sound/` | AT 系の効果音 | 同上 |
| `reel/img/` | リールの図柄画像 | コンパネの「図柄設定」から差し替え |

**素材を全部消しても動きます。** その演出がスキップされるだけで、バナーも遊技も止まりません
(空フォルダで実際に確認済み)。まず消してから、自分の素材を少しずつ足していくのが安全です。

図柄はコンパネの「図柄設定」→ カードに画像をドロップ → 保存、で差し替えられます。

## OBS の設定

| ソース | URL | 幅×高さ |
| --- | --- | --- |
| ブラウザ | `http://localhost:8787/enshutsu/enshutsu_overlay.html` | 1920×1080 (配信解像度に合わせる) |

- 文字サイズはステージ高さに比例するので、**解像度を変えても見た目は崩れません**。
- リールユニットはオーバーレイの中に埋め込まれます (別ソースにしない)。
  設定パネルの「リール」タブで位置と大きさを調整してください。
- 視聴者 HUD は設定パネルの「視聴者」タブで位置・大きさ・表示 ON/OFF を変えられます。
  クレジット制で動かしていないときは自動的に隠れます。

> 既定ではリール (`reelY 62%`) と予告バナー (`bannerY 60%`) が重なります。
> どちらかをずらしてください。

## 別の PC の OBS から見る場合

中継サーバーは既定で `127.0.0.1` だけを待ち受けます。別 PC から繋ぐときだけ:

```
set HOST=0.0.0.0
npm start
```

**同一ネットワークの誰でも遊技者操作 (メダル投入・設定変更) を送れるようになります。**
起動時に警告が出ます。信頼できるネットワークでだけ使ってください。

## うまく動かないとき

| 症状 | 見るところ |
| --- | --- |
| オーバーレイに何も出ない | 中継サーバーが起動しているか (`scripts\dev.cmd status`) |
| コメントに反応しない | ブリッジのコンソール。`[チャット] ... に接続しました` が出ているか |
| チャンネルポイントが反応しない | 報酬名が `rules.json` の `"reward"` と完全一致しているか |
| 「設定変更」が無視される | `guard.mods` に自分の login 名を入れたか (表示名ではない) |
| 視聴者 HUD が出ない | 主制御を `--credit` で起動しているか |
| メダルが入らない | ブリッジに `--no-medals` が付いていないか |

コンパネ (`http://localhost:8787/control/main_control.html`) の「Twitch 連携」カードに
ランプ 3 つ (Twitch / ブリッジ / 中継) と直近のイベントが出ます。まずここを見てください。
疑似イベントのボタンで、Twitch に繋がずに通し確認もできます。
