# はじめて使う人へ

作った本人以外がこのシステムを自分の配信で使うための手順。

---

## 必要なのは 3 行だけ

**認証もアプリ登録もクライアント ID も要りません。**用意するのは自分のチャンネル名だけです。

```
npm install
npm start                                          別の窓で: 中継サーバー
node twitch/twitch_bridge.js --chat あなたのチャンネル名
```

これで視聴者のコメントが貯まるとメダルが入り、スロットが回ります。
OBS のブラウザソースに `http://localhost:8787/enshutsu/enshutsu_overlay.html` を指定してください。

チャンネル名を毎回打ちたくないときは、環境変数 `TWITCH_CHANNEL` に入れるか、
`twitch/config.example.json` を `.run/twitch_config.json` にコピーして `channel` を書けば
`npm run twitch` だけで起動します。

---

## 用意するもの

| | 要件 | 確認 |
| --- | --- | --- |
| Node.js | **18 以降** | `node -v` |
| Python | **3.10 以降** | `py -3 -V` または `python3 -V` |
| OBS | ブラウザソースが使えるもの | — |

Windows なら `setup.bat` をダブルクリックすれば、依存インストールから全起動までやってくれます。

## メダルの入口 (いまはひとつだけ)

| 入口 | 内容 |
| --- | --- |
| **チャット連帯カウンタ** | **30 コメントごとに 120 枚** (約 100 回転)。チャンネル全体で数えるので、1 人が 30 回書いても 30 人が 1 回ずつでも同じ |

**個人にではなくチャンネル全体に貯まる**のが要点です。連投しても得しないので、
スパム対策のルールを足さなくても構造で効きます。
オーバーレイの HUD に「あと ◯◯ コメントで 100 回転」のゲージが出ます。

数えないもの: `!` で始まるコマンド / 既知のボット / 2 文字未満 / 記号や絵文字だけ /
直前と同じ本文 / 同じ人の 10 秒以内の連投。

> **ビッツ・サブスク・フォロー・レイド・チャンネルポイントは、いまは使いません。**
> これらは EventSub (= 認証とクライアント ID) が要るので、いったん外してあります。
> 設計そのものは `doc/twitch連携設計.md` に残っていて、後々足していく予定です。
> (チャンネルポイントはアフィリエイト / パートナー限定の機能で、未到達のチャンネルには
> そもそも存在しません。)

## 自分の配信に合わせて数値を変える

`twitch/rules.json` を開いて調整します。**このファイルだけが人の編集対象**です。

| 項目 | 既定 | 目安 |
| --- | --- | --- |
| `counter.goal` | 30 | チャット何コメントで 120 枚入れるか。**チャットの勢いに合わせてここを動かす** |
| `guard.chatMedalsPerMinute` | 14 | チャット由来の 1 分あたり上限。連続稼働ラインの 82%。ここを上げすぎると止まらなくなる |
| 初コメ歓迎 | `"enabled": false` | 有効にすると、その配信の初コメントに白バナーが出ます |
| 設定変更 | `"enabled": false` | 有効にすると、モデレータと配信者が `!設定変更` で打ち直せます (バッジで判定) |
| 押し順投票 | `"enabled": false` | 有効にすると出玉が確実に減ります (ナビ無視になるため) |

上の 3 つはチャットなので、有効にしても**認証は要りません**。
一方、`kind` が `chat` 以外のルール (レイド・ビッツ・サブスクなど) を足すと、
そこから先は認証と自分で登録したクライアント ID が要ります (`doc/twitch認証の取り方.md`)。

主制御側の起動オプション:

```
scripts\dev.cmd start -Credit        クレジット制 (メダルが尽きたら待機)
```

`--credit-init 500` が配信開始時のクレジット (約 427 回転 ≒ 29 分ぶん) です。
**設定は 1〜2 で運用してください。** 設定 3 以上は機械割が 100% を超えて下皿が増え続け、
視聴者が何もしなくても永久に回ってしまいます。

## 同梱の素材は差し替えてください

`enshutsu/` に入っている画像・音声・動画は **作った本人の素材**です。
そのまま配信に出すと権利の問題になります。

| フォルダ | 中身 | どうするか |
| --- | --- | --- |
| `enshutsu/yokoku/freeze/cutin/` | カットイン画像と音声 | **自分のものに差し替える** |
| `enshutsu/yokoku/freeze/` | フリーズ演出の GIF・動画・効果音 | 同上 |
| `enshutsu/yokoku/banner/sound/` | 予告バナーの効果音 (白/青/緑/赤/金.mp3) | 好きな音を置く。無くても動く |
| `enshutsu/at/sound/` | AT 系の効果音 | 同上 |
| `reel/img/` | リールの図柄画像 | コンパネの「図柄設定」から差し替え |

**素材を全部消しても動きます。** その演出がスキップされるだけで、バナーも遊技も止まりません
(空フォルダで実際に確認済み)。まず消してから、自分の素材を少しずつ足していくのが安全です。

図柄はコンパネの「図柄設定」→ カードに画像をドロップ → 保存、で差し替えられます。

## OBS の設定

| ソース | URL | 幅×高さ |
| --- | --- | --- |
| ブラウザ | `http://localhost:8787/enshutsu/enshutsu_overlay.html` | 1920×1080 (配信解像度に合わせる) |

- 文字サイズはステージ高さに比例するので、**解像度を変えても見た目は崩れません**。
- リールユニットはオーバーレイの中に埋め込まれます (別ソースにしない)。
  設定パネルの「リール」タブで位置と大きさを調整してください。
- 視聴者 HUD は設定パネルの「視聴者」タブで位置・大きさ・表示 ON/OFF を変えられます。
  クレジット制で動かしていないときは自動的に隠れます。

> 既定ではリール (`reelY 62%`) と予告バナー (`bannerY 60%`) が重なります。
> どちらかをずらしてください。

## 別の PC の OBS から見る場合

中継サーバーは既定で `127.0.0.1` だけを待ち受けます。別 PC から繋ぐときだけ:

```
set HOST=0.0.0.0
npm start
```

**同一ネットワークの誰でも遊技者操作 (メダル投入・設定変更) を送れるようになります。**
起動時に警告が出ます。信頼できるネットワークでだけ使ってください。

## うまく動かないとき

| 症状 | 見るところ |
| --- | --- |
| オーバーレイに何も出ない | 中継サーバーが起動しているか (`scripts\dev.cmd status`) |
| コメントに反応しない | ブリッジのコンソール。`[チャット] ... に接続しました` が出ているか |
| コメントしてもメダルが入らない | `counter.goal` (既定 30) まで貯まっているか。HUD のゲージで残り数が見えます |
| 「達成」と出たのにメダルが入らない | 1 分あたりの上限に当たって待っています。ブリッジのログに「あと約◯分で入ります」と出ます。捨てられてはいません |
| 「!設定変更」が無視される | ルールが `"enabled": false` のままでないか。有効にしたうえで、モデレータか配信者のアカウントで打つ |
| 「チャンネル名がありません」で止まる | `--chat あなたのチャンネル名` を付けるか、`TWITCH_CHANNEL` を設定する |
| 視聴者 HUD が出ない | 主制御を `--credit` で起動しているか |
| メダルが入らない | ブリッジに `--no-medals` が付いていないか |

コンパネ (`http://localhost:8787/control/main_control.html`) の「Twitch 連携」カードに
ランプ 3 つ (Twitch / ブリッジ / 中継) と直近のイベントが出ます。まずここを見てください。
疑似イベントのボタン (コメント / コメント×10 / コメント×30) で、Twitch に繋がずに通し確認もできます。

普通のコメントはイベント欄には出ません (本文を配信画面に出さないため)。
**30 コメント貯まったときだけ**「counter チャット 30コメント達成」と出ます。

> ブリッジは配信開始 (stream.online) を検知できないので、連帯カウンタとランキングは
> **ブリッジを起動したところがリセット点**になります。配信ごとに起動し直してください。
