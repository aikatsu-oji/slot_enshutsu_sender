筐体ビュー(reel/reel.html)をオーバーレイ内に埋め込み、下からスライドして出し入れします。 主制御と連動(mode=link)し、中継サーバー(8787)の state を受けてリールが回ります。 出し入れの状態は保存され、次回起動時も引き継がれます。

コンパネの「リールを液晶に入れる / 出す」ボタン、または dev.cmd send reelIn / reelOut / reelToggle でも操作できます。
オンにすると筐体ビュー側のナビランプを表示します(切替時に筐体ビューを読み直します)。押し順の表示はここか、押し順ナビに割り当てたオーサリングのシーンで出します。
リールの回転開始音・停止音は enshutsu/real/ に start / stop (停止順に鳴らし分けるなら stop1 / stop2 / stop3) の名前で置くと鳴ります (拡張子は mp3/wav/ogg/m4a、無ければ無音)。音量は「設定」タブの音量に従います。
