実機系の効果音(任意)。筐体ビュー reel/reel.html が起動時に /api/list で読み込みます。
ファイルが無ければその音は鳴りません(リールはそのまま回ります)。
拡張子は mp3 / wav / ogg / m4a のいずれか。ファイル名(拡張子を除く)で対応付けます。

  start   … リール回転開始(レバーオン)。1ゲームにつき1回
  stop    … リール停止。3リールとも同じ音でよいときはこれだけ置く
  stop1   … 第1停止(省略時は stop)
  stop2   … 第2停止(省略時は stop)
  stop3   … 第3停止(省略時は stop)

例: start.wav, stop.wav / start.wav, stop1.mp3, stop2.mp3, stop3.mp3

音量:
  ・筐体ビュー単体   … URL の ?vol=0.8 (0〜1)。?sound=0 で消音
  ・オーバーレイ内   … 設定パネル「設定」タブ →「基本設定」の「効果音の音量」に従う

追加・差し替え後は筐体ビュー(オーバーレイに埋め込んでいる場合はオーバーレイ)を
再読み込みしてください。file:// で開いた場合は探しに行かないため無音になります。
